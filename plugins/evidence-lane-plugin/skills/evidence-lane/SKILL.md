# Evidence Lane

Read [shared boundaries](../run-project-lifecycle/references/shared-boundaries.md) before using the workflow.
Use [owned action references](references/actions.json) and the live MCP schemas for exact arguments.

Read `client_context` and `workflow_catalog` to identify the current
authenticated client and the relevant first-class skill. `project_catalog`
requires the separately granted local project-administration capability.
Use `render_runtime_panel` for measured engine/Flash/host observations and
`render_project_panel` for a bounded current Plan page, session and lane heads
in one selected project. These read-only views have an MCP Apps resource and
structured-data fallback. Page with `offset` and `limit` through the native
action; tab navigation never submits commands. Registered tools/lanes do not
establish execution, installed Studio readiness or native task attestation.
Use `project_evidence_history` for bounded exact published project evidence head coordinator references and `project_evidence_heads_compare`
to compare two of them. The result describes recorded lane database heads;
it does not recover historical file contents or counts. Same-byte lane
republication is disclosed separately. These reads do not change the Plan.
For a selected project, use `project_status`, the owning authority's bounded
read, or `delta_query` for a scoped question during work. Use `search` for
literal matches across separate registered authorities and current sector
snapshots, or `lane_search` for one exact lane. Inspect every returned arm's
coverage: unavailable content search, uninitialized storage, no hit, truncated
snapshot catalogs and truncated result pages mean different things. Select a
smaller lane/snapshot page when the output budget is exceeded. Follow an exact
owning action and snapshot for subsequent reads. Stored current pointers do not
prove source files are still unchanged; search performs no refresh. Use
`retrieval=tfidf`, `hybrid` (FTS BM25 and TF/IDF reciprocal-rank fusion), or
`rank_bm25` to rerank a bounded `candidate_limit` from one owning sector snapshot.
Follow `ranking.selected` row indices into the unchanged owner result; these
scores are derived only within that candidate page. The owner and candidate
digests retain exact attribution. Unsupported authority ranking is disclosed
as unavailable; use its original FTS reader for that authority. Optional
`rank_bm25` requires its measured library route, without a silent fallback. Use
`lane_catalog` for actual authority/sector definitions and registered reader
contracts, and `lane_status` for one selected physical lane's database/schema
and recorded view state. Catalog membership does not prove installation. For
`lane_fetch`, select an exact snapshot and path; keep primary and original-source
representations distinct. Follow its owning typed query for structural facts.
Use lane view reads
only for the selected lane and current published reference. Use
`lifecycle_transition_law` to inspect the executable Plan/session transition
rules and current UOP workflow gates. Its catalog states its coverage and the
separate owners of other states; a listed transition is not permission to run it.
Informational
queries do not begin work, change a Plan, attach a session or grant access.
