# Evidence Lane status

Call `pv_status` for `$ARGUMENTS`.

Show the registered source authority, active lanes, accepted PV, highest
accepted ordinal, entry PV if an active session exists, pointer generation,
accepted manifest/package seal, ancestry depth, live freshness, preserved
candidates, pending HIL, and task backlog count. Label candidates
`UNACCEPTED_CANDIDATE`. Do not boot or mutate.
