# Evidence Lane v4

Evidence Lane keeps project work, source evidence and scoped tools together through a persistent engine and visible Studio.

The v4 development source uses one selected external SQLite database and content-addressed files per project. Plan, ChatLineage, Canon, Project Memory, Learning, source provenance and sector profiles retain separate ownership. Each lane keeps the artifact files and toolchain its operations require.

Native MCP clients connect to the engine's typed action registry. An optional HTTPS engine supports separately configured remote project access. Studio remains visible in development and shipping, with open, minimize and reopen controls.

This branch contains an uninstalled preinstall candidate. A tool or source file being present is not a claim that its installed v4 operation is qualified. Public release documentation and complete operation coverage follow installed-runtime qualification.
