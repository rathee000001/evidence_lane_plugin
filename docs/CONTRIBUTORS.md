OpenAI Codex was used as an AI-assisted engineering and documentation tool under Praveen Rathee's direction and review. Codex helped inspect sources, implement and test changes, generate drafts and assets, operate development tools, and maintain evidence across the build.

Codex is not represented as a human author, owner, approver, employee, or legal contributor. AI output was treated as proposed work requiring source checks, tests, review, and human direction.

Official OpenAI and Codex documentation informed supported product and tool behavior. Those references remain owned and licensed by OpenAI.

## Repository and delivery provenance

Git and GitHub provide the source history, repository, releases, issue/PR conventions, GitHub Actions, and CodeQL surfaces used by the project. Vercel provides the public website hosting. The live website is a public information surface, separate from the local Windows Studio and project engine.

Earlier Evidence Lane revisions and public Git history informed the current product. Historical behavior was not copied into v4 merely because it existed; retained capabilities were rechecked against current source and explicit product decisions.

Major foundations include:

- pytest, Ruff, mypy, Playwright, Mermaid, and Graphviz;

- Blender and the visual/open tooling used during product design;
- security, packaging, build, and observability projects referenced by the current toolchain.

This grouped acknowledgement is intended to thank the ecosystem without inventing a hand-maintained exhaustive roster. The exact dependency and license records remain authoritative.
