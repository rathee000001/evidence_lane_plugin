## Public workflows

Evidence Lane currently presents 24 first-class workflows. They are separate because opening a project, changing a Plan, adding sources, configuring a connection, executing work, and recovering state have different consequences and checks.

See the [Workflow Guide](WORKFLOW_GUIDE.md) or open any guide in the [workflow directory](workflows/evidence-lane.md).

## Documentation standard

Every workflow guide states:

- the user's intention;
- when the workflow fits;
- what must already be selected;
- what the user will see happen;
- what result and evidence it produces;
- what Studio can display;
- what the workflow does not do;
- how failure or uncertainty is reported;
- a practical example.

Technical identifiers appear only in expandable reference sections. They are not the product story.
