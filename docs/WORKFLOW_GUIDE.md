## Choosing correctly

Ask what must change:

- If nothing should change, start with an inspection workflow.
- If source bytes changed, use source refresh.
- If the intended outcome or task order changed, steer the Plan.
- If the current task should run, use Plan execution.
- If access changes, use the specific connection configuration or withdrawal workflow.
- If ownership moves between clients, use handoff.
- If effects are uncertain, inspect or recover before replaying.

## Representative stages

Each workflow guide shows representative stages from current contracts. The selected project, source type, task, tool readiness, and missing choices may add or stop stages. The examples are intentions to express in Codex, not commands sent by this documentation.
